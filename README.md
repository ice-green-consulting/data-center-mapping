# Data Center Mapping Initiative

**Part of the ICE Green Consulting Pan-Global Sovereign Digital Ecosystem.**

## Project Goal
To map, verify, and connect Africa's sovereign data centers to create a localized, secure infrastructure network for the Kindred™ Network and NACOS talent.

## How to Contribute
We are actively gathering data across the continent. If you have information on a data center to add, please follow these steps:
1. Go to the **Issues** tab at the top of this page.
2. Click **New Issue**.
3. Title it: `DATA + [Country]` (e.g., DATA + Nigeria).
4. Provide the location, capacity, and ownership details in the description.

## The Pan-Global Flywheel
By mapping this infrastructure, we ensure that when our NACOS-trained digital workers build applications, they are building on locally owned, sovereign technology.
